# 🧠 AI Trustworthiness Evaluation Framework

A structured framework for evaluating the **trustworthiness of machine learning models** in high-stakes domains such as healthcare decision support systems.

This project goes beyond traditional accuracy metrics by incorporating **robustness, fairness, and interpretability** into a unified evaluation approach.

---

## 🎯 Objective

To provide a **multi-dimensional evaluation framework** that enables better model selection in sensitive applications where reliability and transparency are critical.

---

## ⚙️ Methodology

The framework evaluates models across four key dimensions:

- **Predictive Performance**
  - Accuracy
  - ROC-AUC

- **Robustness**
  - Sensitivity to noise and perturbations
  - Stability under data variation

- **Fairness**
  - Performance consistency across subgroups

- **Interpretability**
  - Feature importance analysis (permutation importance)

---

## 🧮 Trustworthiness Score

A **composite Trustworthiness Score** is computed using:

- **Analytic Hierarchy Process (AHP)**
- Weighted combination of evaluation criteria
- Supports transparent and explainable model ranking

---

## 🤖 Models Evaluated
